## Serviciu indisponibil

Aplicația poate răspunde cu HTTP 503 când serviciul nu este disponibil. Mesajul explică problema și oferă alternative. Un termen de remediere apare doar dacă este cunoscut.

<Preview name="ServiceUnavailable" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function ServiceUnavailableExample() {
  return (
    <R.ServiceStatusPage
      title="Serviciul este în mentenanță"
      returnHref={`/${locale}/patterns/start/`}
      returnLabel="Revino la pagina serviciului"
    >
      <p>
        În acest scenariu, serviciul este oprit pentru lucrări programate. Va fi
        disponibil din nou pe 26 octombrie, la ora 09:00.
      </p>
      <p>
        Dacă solicitarea este urgentă, poți folosi o altă modalitate de contact.{' '}
        <R.Link href={`/${locale}/patterns/contact/`}>
          Vezi opțiunile de ajutor
        </R.Link>
      </p>
    </R.ServiceStatusPage>
  );
}
~~~

## Pagina nu a fost găsită

Aplicația răspunde cu HTTP 404 și afișează un titlu clar. Pagina oferă linkuri către secțiunile utile și ajutor, fără să sugereze că utilizatorul este de vină.

<Preview name="PageNotFound" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx

import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function PageNotFoundExample() {
  return (
    <R.ServiceStatusPage
      title="Pagina nu a fost găsită"
      returnHref={`/${locale}/patterns/start/`}
      returnLabel="Mergi la pagina serviciului"

        salvat, pagina poate avea acum o altă adresă.

          Cere ajutor dacă nu găsești informația căutată
        </R.Link>
      </p>
    </R.ServiceStatusPage>
  );
}
~~~

## Eroare a serviciului

Mesajul distinge o problemă tehnică de o eroare în datele completate. Precizează dacă cererea a fost trimisă și cum se poate încerca din nou sau cere ajutor, fără riscul unor plăți duplicate.

<Preview name="ServiceProblem" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx

import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function ServiceProblemExample() {
  return (
    <R.ServiceStatusPage
      title="Nu am putut trimite cererea"
      returnHref={`/${locale}/patterns/question/`}
      returnLabel="Revino la formular"
    >
      <p>
        A apărut o problemă tehnică. Cererea nu a fost trimisă. Poți încerca din
        nou.
      </p>
      <p>
        Dacă problema persistă,{' '}
        <R.Link href={`/${locale}/patterns/contact/`}>
          contactează echipa serviciului
        </R.Link>
        .
      </p>
    </R.ServiceStatusPage>
  );
}
~~~

## Întreruperea unui proces

Pagina explică de ce procesul a fost întrerupt, ce informații s-au salvat și cum se poate continua sau cere ajutor. Redirecționările automate pot face dificilă revenirea la pasul curent.

<div className="sdr-example-code">
<Tabs>
<TabItem label="React">

}

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
