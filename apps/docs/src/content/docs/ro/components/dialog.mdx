## Utilizare

Dialogurile nu se deschid unele în altele. Escape sau un click în exterior închide dialogul și readuce focusul pe butonul care l-a deschis. Deschiderea necesită JavaScript.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `trigger` | `string` | Da |
| `title` | `string` | Da |
| `children` | `ReactNode` | Da |
| `closeLabel` | `string` | Da |
| `drawer` | `boolean \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Panou lateral

Drawer deschide același dialog modal la marginea ecranului. Focusul rămâne în interior cât timp este deschis. Se închide cu Escape, cu butonul de închidere sau printr-un click în exterior.
