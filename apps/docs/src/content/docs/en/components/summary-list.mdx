## Usage

Change links must name the answer, such as Change address.



## API

| Property | Type | Required |
|---|---|---|
| `items` | `SummaryItem[]` | Yes |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.

## Without actions

DataList is a SummaryList alias suited to descriptive key-value data without change links.

<Preview name="DataList" locale="en" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'en';

export function DataListExample() {
  return (
    <R.DataList
      items={[
        { key: 'Reference', value: 'SDR-0042' },
        { key: 'Status', value: <R.Tag tone="success">Received</R.Tag> },
      ]}
    />
  );
}
~~~

</TabItem>
