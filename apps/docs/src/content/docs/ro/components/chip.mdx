## Utilizare

Pentru variante interactive sunt disponibile ActionChip și DismissibleChip.



## API

Acceptă atributele HTML ale elementului nativ. Tipurile TypeScript din sursă descriu proprietățile disponibile.

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Cu acțiune

Varianta interactivă este un buton pentru o acțiune secundară. Chip-ul simplu afișează doar o etichetă.

import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function ActionChipExample() {
  const [count, setCount] = useState(0);
  return (
    <R.Cluster>
      <R.ActionChip onClick={() => setCount(count + 1)}>

  );
}

## Cu opțiune de eliminare

Varianta reprezintă un filtru selectat care poate fi eliminat. onRemove sau evenimentul ediției HTML transmite acțiunea către aplicație. Aplicația actualizează lista și mută focusul pe un element potrivit.

<Preview name="DismissibleChip" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function DismissibleChipExample() {
  const [visible, setVisible] = useState(true);
  return (
    <R.Cluster>
      <R.Button
        id="restore-filter"
        variant="secondary"
        onClick={() => setVisible(true)}
      >
        Adaugă filtrul din nou
      </R.Button>
      {visible && (
        <R.DismissibleChip
          removeLabel="Elimină filtrul Brașov"
          onRemove={() => {
            setVisible(false);
            document.getElementById('restore-filter')?.focus();
          }}
        >
          Brașov
        </R.DismissibleChip>
      )}
    </R.Cluster>
  );
}
~~~

</TabItem>
