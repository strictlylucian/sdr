## Usage

Do not shrink essential instructions to fit a fixed container.



## API

| Property | Type | Required |
|---|---|---|
| `size` | `"sm" \| "md" \| "lg" \| "xs" \| undefined` | No |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.



## Accessibility

Composition accessibility depends on labels, element semantics, focus order and application context. Library themes and behaviours are checked against the documented examples; those results do not assess the consuming service. The matrix and limitations are described in [the accessibility guide](/en/accessibility/).
