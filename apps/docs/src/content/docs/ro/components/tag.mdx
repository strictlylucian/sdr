## Utilizare

Eticheta nu este interactivă. Pentru o acțiune sau navigare sunt potrivite un buton sau un link.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `tone` | `Tone \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Badge numeric

Badge afișează un număr într-un format compact. Textul alăturat explică ce se numără; pentru stări sunt potrivite etichetele text.

## Accesibilitate
