## Example

Keep a stable service identity and name each navigation landmark. For client routing, update page title, history, focus and announcements together.

<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'en';

export function ServiceNavigationExample() {
  return (
    <R.ServiceNavigation
      label="Service"
      items={[
        { label: 'Overview', href: `/${locale}/`, current: true },
        { label: 'Components', href: `/${locale}/components/` },
      ]}
      menuLabel="Menu"
    />
  );
}
~~~

## Service integration

Examples use library components. Server validation, messaging, payment processing and persistence are implemented by the application. Demonstration interactions stay local and do not persist after reload. JavaScript setup is documented once in [Get started](/en/getting-started/). Accessibility details are in [the accessibility guide](/en/accessibility/).
