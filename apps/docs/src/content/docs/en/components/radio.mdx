## Usage

All radios in a question must share a name; different questions need different names.



## API

| Property | Type | Required |
|---|---|---|
| `label` | `ReactNode` | Yes |
| `hint` | `ReactNode` | No |
| `error` | `ReactNode` | No |
| `children` | `ReactNode` | No |
| `conditionalId` | `string \| undefined` | No |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.

## With conditional fields

Related fields are passed as children of Radio or Checkbox. conditionalId optionally provides the related fieldset ID. A short, directly related question works best; vertical choices keep the relationship clear. The example starts with an email validation error to show the nested error rail. Selection reveals the fields without moving focus. Inactive content stays mounted, hidden and disabled: values are retained, but excluded from native validation and FormData. The application owns validation, error summaries and submitted data, including any custom form-state library. Without JavaScript all related fields remain visible. In HTML, data-sdr-component="conditional-choice" opts in; aria-controls references the direct child fieldset marked data-sdr-conditional. Programmatic checked/disabled changes require a bubbling change event or sdr:refresh on the choice container. Native form reset restores the reveal state. Complex branching is better handled on separate pages. Manual screen-reader evaluation is still pending.

import * as R from '@strictlylucian/sdr-react';

export function ConditionalRadioExample() {
  return (
    <R.Fieldset
      legend="How would you prefer to be contacted?"
      hint="Select one option. Selecting email or phone reveals a related field."
    >
      <R.Radio
        id="contact-email"
        name="contact-method"
        value="email"
        label="Email"
        defaultChecked
      >
        <R.TextInput
          id="contact-email-address"
          name="email-address"
          type="email"
          autoComplete="email"
          label="Email address"
          error="Enter your email address."
        />
      </R.Radio>
      <R.Radio
        id="contact-phone"
        name="contact-method"
        value="phone"
        label="Phone"
      >
        <R.TextInput
          id="contact-phone-number"
          name="phone-number"
          type="tel"
          autoComplete="tel"
          label="Phone number"
        />
      </R.Radio>
      <R.Radio
        id="contact-post"
        name="contact-method"
        value="post"
        label="By post"
      />
    </R.Fieldset>

}
