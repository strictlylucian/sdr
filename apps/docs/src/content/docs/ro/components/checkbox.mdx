## Stare de eroare

Mesajul de eroare este asociat controlului prin aria-describedby, iar aria-invalid indică starea. În React, proprietatea error activează prezentarea; aplicația stabilește regulile de validare și momentul afișării mesajului. Ediția HTML folosește aceeași structură și aceleași clase CSS.

## Read-only

Acest control nu are un atribut readonly nativ în HTML. Pentru o valoare care nu poate fi modificată, exemplul folosește SummaryList. Dacă valoarea trebuie trimisă, aplicația o gestionează separat; disabled exclude controlul din datele formularului.

<Preview name="CheckboxReadOnly" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function CheckboxReadOnlyExample() {
  return (
    <R.SummaryList
      items={[{ key: 'Cum vrei să te contactăm?', value: 'Email' }]}
    />
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div
  lang="ro"
  data-sdr-theme="light"
  data-sdr-density="comfortable"
  class="sdr"
>
  <dl class="sdr-summary">
    <div class="sdr-summary__row">
      <dt>Cum vrei să te contactăm?</dt>
      <dd>Email</dd>
    </div>
  </dl>
</div>
~~~

## Utilizare

Opțiunile care răspund aceleiași întrebări se grupează cu Fieldset. Poate fi utilă și opțiunea „Niciuna dintre cele de mai sus”.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `label` | `ReactNode` | Da |
| `hint` | `ReactNode` | Nu |
| `error` | `ReactNode` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Switch

Switch activează sau dezactivează o setare și păstrează semantica unui checkbox. Aplicația stabilește dacă modificarea se salvează imediat.

<Preview name="Switch" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function SwitchExample() {
  return (
    <R.Switch
      name="notifications"
      label="Primește notificări prin email"
      hint="Te anunțăm când se schimbă starea cererii."
    />
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div
  lang="ro"
  data-sdr-theme="light"
  data-sdr-density="comfortable"
  class="sdr"
>
  <div class="sdr-choice-field">
    <label
      class="sdr-choice sdr-choice--switch"
      for="notifications"
      ><input
        id="notifications"
        class="sdr-choice__input"
        type="checkbox"
        role="switch"
        aria-describedby="notifications-hint"
        name="notifications"
      /><span class="sdr-choice__content"
        ><span>Primește notificări prin email</span
        ><span
          id="notifications-hint"
          class="sdr-hint"
          >Te anunțăm când se schimbă starea cererii.</span
        ></span
      ></label
    >
  </div>
</div>
~~~
