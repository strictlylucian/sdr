## Numere de telefon

Câmpul folosește type=tel și autocomplete=tel. Acceptă prefixe internaționale, spații și numere copiate. Textul precizează dacă numărul va fi folosit pentru SMS-uri sau apeluri.

<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function PhoneNumberExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="phone"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <h3>La ce număr te putem contacta?</h3>
      <R.TextInput
        label="Număr de telefon"
        type="tel"
        name="phone"
        autoComplete="tel"
        required
        hint="Te sunăm doar dacă avem întrebări despre cerere. Pentru numere din străinătate, include prefixul țării. Folosește date fictive în exemplu."
      />
      <div>
        <R.Button type="submit">Continuă</R.Button>
      </div>
      <R.Link href={`/${locale}/patterns/contact-details/#variant-email`}>
        Prefer să primesc răspunsul prin email
      </R.Link>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Exemplu finalizat. Numărul nu a fost salvat și nu s-a trimis niciun SMS.
      </p>
    </form>
  );
}
~~~

## Adrese de email

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
