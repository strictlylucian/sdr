## Example

Use three fields for memorable dates, a native picker for appointments, and state the expected time zone for deadlines. Validate calendar correctness on the server.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'en';

export function DateInputExample() {
  return (
    <R.DateInput
      legend="Date of birth"
      name="birth"
      hint="For example, 27 3 1990"
      labels={{ day: 'Day', month: 'Month', year: 'Year' }}
    />
  );
}
~~~

## Service integration

Examples use library components. Server validation, messaging, payment processing and persistence are implemented by the application. Demonstration interactions stay local and do not persist after reload. JavaScript setup is documented once in [Get started](/en/getting-started/). Accessibility details are in [the accessibility guide](/en/accessibility/).
