## Utilizare

Fiecare link de modificare precizează răspunsul la care se referă, inclusiv când este citit separat de restul paginii.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `items` | `SummaryItem[]` | Da |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Fără acțiuni

DataList este un alias pentru SummaryList, potrivit pentru perechi de denumiri și valori, fără linkuri de modificare.

import { useState } from 'react';

const locale = 'ro';

  return (
    <R.DataList
      items={[
        { key: 'Numărul cererii', value: 'SDR-0042' },
        { key: 'Stare', value: <R.Tag tone="success">Primită</R.Tag> },

  );
}
