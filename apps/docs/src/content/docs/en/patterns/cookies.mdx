## Example

List cookie purposes, durations and providers. Optional scripts stay off until consent, and changing or withdrawing consent must be as easy as accepting.

<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'en';

export function CookieBannerExample() {
  const [choice, setChoice] = useState('');
  return (
    <R.Stack>
      {!choice && (
        <R.CookieBanner
          title="Cookie preferences"
          acceptLabel="Accept analytics"
          rejectLabel="Reject analytics"
          onAccept={() =>
            setChoice('Analytics accepted in this demonstration.')
          }
          onReject={() =>
            setChoice('Analytics rejected in this demonstration.')
          }
        >
          Optional cookies remain off until you choose.
        </R.CookieBanner>
      )}
      <p
        role="status"
        hidden={!choice}
      >
        {choice}
      </p>
    </R.Stack>
  );
}
~~~

## Service integration

Examples use library components. Server validation, messaging, payment processing and persistence are implemented by the application. Demonstration interactions stay local and do not persist after reload. JavaScript setup is documented once in [Get started](/en/getting-started/). Accessibility details are in [the accessibility guide](/en/accessibility/).
