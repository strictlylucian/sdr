## Exemplu

Schimbarea limbii păstrează, pe cât posibil, pagina și secțiunea curentă. Documentul are atributul lang, iar pasajele în alte limbi sunt marcate separat. Selectorul folosește numele limbilor, nu steaguri.

<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function LanguageNavigationExample() {
  return (
    <R.LanguageNavigation
      label="Limbă"
      items={[
        {
          lang: 'ro',
          label: 'Română',
          href: '/ro/components/language-navigation/',
          current: locale === 'ro',
        },
        {
          lang: 'en',
          label: 'English',
          href: '/en/components/language-navigation/',
          current: locale === 'en',
        },
      ]}
    />
  );
}
~~~

</TabItem>

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
