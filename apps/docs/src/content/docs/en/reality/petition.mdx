The Ministry of Defence sectoral pension office’s form is a scanned page with boxes for identification, correspondence and petition details. Fields have fixed widths and writing space is limited by the sheet. The inspected scan contains no selectable text.

## What SDR proposes

Identity, address and describing the request have separate steps. Labels sit above controls, widths adapt to the screen and the petition has a resizable text area. Errors are associated with questions and answers can be reviewed.

## Mapping to the original

| Published document | Proposal |
| --- | --- |
| Identity and identity document | The first step retains names, personal number, email and document details. |
| County, town, number, block, entrance, floor, apartment | The second step retains these fields. Optional Street is a proposed addition: absent from the inspected PDF. |
| County, capacity, pension file | Separate questions in the final step. |
| Petition text box | A text area without the scanned sheet’s visual writing limit. |

Source fields are retained for a traceable comparison. A pilot should review the need for a personal number, document details and required fields with the institution. File uploads, authentication, signing and petition registration are not implemented.
