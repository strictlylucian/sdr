## Usage

Use ActionChip or DismissibleChip when an action is available.



## API

Accepts HTML attributes for its native element. See the typed source.

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.

## Action chip

The interactive variant uses a button for a contextual action. A static chip remains a non-interactive label.

<Preview name="ActionChip" locale="en" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'en';

export function ActionChipExample() {
  const [count, setCount] = useState(0);
  return (
    <R.Cluster>
      <R.ActionChip onClick={() => setCount(count + 1)}>
        Add a filter
      </R.ActionChip>
      <span role="status">{count}</span>
    </R.Cluster>
  );
}
~~~

</TabItem>

## Dismissible chip

The removable variant represents a selected filter. onRemove or the portable event reports the action; the application manages the list and focus destination.

<Preview name="DismissibleChip" locale="en" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'en';

export function DismissibleChipExample() {
  const [visible, setVisible] = useState(true);
  return (
    <R.Cluster>
      <R.Button
        id="restore-filter"
        variant="secondary"
        onClick={() => setVisible(true)}
      >
        Restore filter
      </R.Button>
      {visible && (
        <R.DismissibleChip
          removeLabel="Remove Brașov filter"
          onRemove={() => {
            setVisible(false);
            document.getElementById('restore-filter')?.focus();
          }}
        >
          Brașov
        </R.DismissibleChip>
      )}
    </R.Cluster>
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div
  lang="en"
  data-sdr-theme="light"
  data-sdr-density="comfortable"
  class="sdr"
>
  <div class="sdr-cluster sdr-u-gap-3">
    <button
      id="restore-filter"
      type="button"
      class="sdr-button sdr-button--secondary"
    >
      Restore filter</button
    ><button
      class="sdr-chip"
      type="button"
      aria-label="Remove Brașov filter"
      data-sdr-component="actions"
      data-sdr-action="remove"
    >
      Brașov<span aria-hidden="true">×</span>
    </button>
  </div>
</div>
~~~

## Accessibility

Composition accessibility depends on labels, element semantics, focus order and application context. Library themes and behaviours are checked against the documented examples; those results do not assess the consuming service. The matrix and limitations are described in [the accessibility guide](/en/accessibility/).
