## Service patterns

26 patterns cover questions, validation, navigation, documents, checking answers and confirmation. Personal details, addresses and conventions are adapted to Romanian services. Each service must research these patterns with the people who use it.

Variants are grouped within their parent patterns, with distinct examples and source for each scenario.

## Known boundaries

There is no editable or virtualised grid, custom combobox, custom calendar or ARIA tree widget yet. The date picker is native, hierarchical navigation uses disclosures, and the menu uses ordinary links. Tables sort locally. The host implements persistence, server validation and business actions.
