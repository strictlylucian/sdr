## Exemplu

Condițiile, costurile, documentele necesare și durata estimată sunt explicate înainte de colectarea datelor personale. Dacă persoana nu îndeplinește condițiile, pagina oferă o alternativă sau indică unde poate cere ajutor.

~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function EligibilityExample() {
  const [answer, setAnswer] = useState('');
  return (
    <form
      data-sdr-pattern-demo="eligibility"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setAnswer(String(new FormData(form).get('resident')));
        requestAnimationFrame(() =>
          form
            .querySelector<HTMLElement>(
              '[data-sdr-pattern-outcome]:not([hidden])',
            )!
            .focus(),
        );
      }}
    >
      <R.Fieldset legend="Locuiești în localitatea în care depui cererea?">
        <R.Radio
          name="resident"
          value="yes"
          label="Da"
          required
        />
        <R.Radio
          name="resident"
          value="no"
          label="Nu"
          required
        />
      </R.Fieldset>
      <div>
        <R.Button type="submit">Verifică</R.Button>
      </div>
      <div
        data-sdr-pattern-outcome="yes"
        tabIndex={-1}
        hidden={answer !== 'yes'}
      >
        <R.Alert
          tone="success"
          title="Poți continua cererea"
        >
          <R.Link href={`/${locale}/patterns/start/`}>
            Vezi documentele și pașii necesari
          </R.Link>
        </R.Alert>
      </div>
      <div
        data-sdr-pattern-outcome="no"
        tabIndex={-1}
        hidden={answer !== 'no'}
      >
        <R.Alert
          tone="warning"
          title="Există o altă opțiune"
        >
          <R.Stack gap={3}>
            <p>Poți cere ajutor pentru a găsi instituția potrivită.</p>
            <R.Link href={`/${locale}/patterns/contact/`}>
              Vezi opțiunile de contact
            </R.Link>
          </R.Stack>
        </R.Alert>
      </div>
    </form>
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
