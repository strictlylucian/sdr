## Stare de eroare

Mesajul de eroare este asociat controlului prin aria-describedby, iar aria-invalid indică starea. În React, proprietatea error activează prezentarea; aplicația stabilește regulile de validare și momentul afișării mesajului. Ediția HTML folosește aceeași structură și aceleași clase CSS.

## Disabled

Atributul disabled dezactivează controlul, îl exclude din navigarea cu Tab și din datele trimise cu formularul. La grupuri, disabled se aplică pe fieldset. Un control indisponibil poate avea o explicație vizibilă în apropiere.

## Read-only

Atributul readOnly (readonly în HTML) păstrează valoarea vizibilă și inclusă în datele formularului. Câmpurile de text pot primi focus, iar conținutul poate fi selectat și copiat, fără a putea fi modificat. Navigarea câmpurilor native de dată și oră urmează comportamentul browserului. La grupul de dată și la Fieldset, starea se aplică fiecărui câmp de text.

## Utilizare

Este potrivită când răspunsul nu încape într-un câmp simplu. O înălțime fixă nu trebuie să ascundă textul introdus.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `label` | `ReactNode` | Da |
| `hint` | `ReactNode` | Nu |
| `error` | `ReactNode` | Nu |
| `id` | `string \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Cu contor de caractere

CharacterCount adaugă un contor lângă Textarea. Numără puncte de cod Unicode, nu întotdeauna caracterele percepute vizual. Textul nu este tăiat automat; limita se verifică în aplicație și pe server.

<Preview name="CharacterCount" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';
import { createInstance } from 'i18next';

// Application-owned translations; SDR only receives the formatter callback.
const i18n = createInstance();
void i18n.init({
  lng: 'ro',
  initAsync: false,
  fallbackLng: false,
  resources: {
    ro: {
      translation: {
        remaining_one: '{count} caracter rămas',
        remaining_few: '{count} caractere rămase',
        remaining_other: '{count} de caractere rămase',
        over_one: 'Ai depășit limita cu {count} caracter',
        over_few: 'Ai depășit limita cu {count} caractere',
        over_other: 'Ai depășit limita cu {count} de caractere',
      },
    },
  },
  interpolation: { prefix: '{', suffix: '}', escapeValue: false },
});
const formatCount = (remaining: number) =>
  i18n.t(remaining < 0 ? 'over' : 'remaining', { count: Math.abs(remaining) });

const locale = 'ro';

export function CharacterCountExample() {
  return (
    <R.CharacterCount
      id="description"
      label="Descrie situația"
      name="description"
      limit={200}
      formatCount={(remaining) => formatCount(remaining)}
    />
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div
  lang="ro"
  data-sdr-theme="light"
  data-sdr-density="comfortable"
  class="sdr"
>
  <div
    data-sdr-component="character-count"
    data-sdr-limit="200"
    class="sdr-stack sdr-u-gap-2"
  >
    <div class="sdr-field">
      <label
        class="sdr-label"
        for="description"
        >Descrie situația</label
      ><textarea
        name="description"
        id="description"
        aria-describedby="description-count"
        class="sdr-textarea"
      ></textarea>
    </div>
    <p
      id="description-count"
      class="sdr-character-count"
      data-sdr-count="true"
      aria-live="polite"
      aria-atomic="true"
    >
      200 de caractere rămase
    </p>
  </div>
</div>
~~~
