## Utilizare

Textul linkului descrie destinația. Comportamentul obișnuit al browserului, inclusiv deschiderea într-un tab nou, rămâne disponibil.



## API

Acceptă atributele HTML ale elementului nativ. Tipurile TypeScript din sursă descriu proprietățile disponibile.

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Înapoi

Linkul cu săgeată înapoi are o destinație explicită. Nu depinde de istoricul browserului.

<Preview name="BackLink" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function BackLinkExample() {
  return (
    <R.BackLink
      href={`/${locale}/components/`}
      children="Înapoi"
    />
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div
  lang="ro"
  data-sdr-theme="light"
  data-sdr-density="comfortable"
  class="sdr"
>
  <a
    href="/ro/components/"
    class="sdr-back"
    ><span aria-hidden="true">←</span>Înapoi</a
  >
</div>
~~~

[Configurare inițială](/ro/getting-started/)

</TabItem>
</Tabs>
</div>

## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
