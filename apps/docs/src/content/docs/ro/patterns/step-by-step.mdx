## Exemplu

Ghidul prezintă etapele unui proces în ordine, cu informațiile necesare și linkuri către pașii respectivi. El explică procesul în ansamblu; indicatorul de progres arată doar unde se află utilizatorul într-un formular.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function StepByStepExample() {
  return (
    <R.StepByStep
      title="Cum depui cererea"
      steps={[
        {
          title: 'Verifică eligibilitatea',
          content: 'Citește condițiile înainte de a începe.',
        },
        {
          title: 'Pregătește documentele',
          content: 'Verifică formatele acceptate.',
        },
        {
          title: 'Verifică și trimite',
          content: 'Păstrează numărul de referință.',
        },
      ]}
    />
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
