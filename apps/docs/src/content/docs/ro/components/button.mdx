## Utilizare

Varianta primary evidențiază acțiunea principală; secondary are fundal neutru, iar tertiary are aspect de link. danger folosește roșu pentru acțiuni distructive, iar danger-secondary oferă o alternativă cu contur. Etichetele descriu consecința, de exemplu „Șterge ciorna”. Focusul de tastatură și starea apăsată folosesc galben. Butoanele sunt type="button" implicit; trimiterea formularului folosește type="submit". Validarea și confirmarea acțiunilor aparțin aplicației.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `variant` | `"primary" \| "secondary" \| "tertiary" \| "danger" \| "danger-secondary" \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Link cu aspect de buton

Varianta folosește un element a cu href, afișat ca buton pentru a evidenția o destinație importantă. Păstrează comportamentul unui link obișnuit.

## Buton toggle

aria-pressed arată dacă opțiunea este activă. defaultPressed stabilește starea inițială, iar eticheta rămâne aceeași la activare și dezactivare.
