~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function ToastExample() {
  const [show, setShow] = useState(false);
  const [generation, setGeneration] = useState(0);
  const message = 'Modificările au fost salvate.';
  return (
    <R.Stack>
      <div
        role="status"
        aria-atomic="true"
        className="sdr-visually-hidden"
        data-sdr-toast-status
      >
        {show && <span key={generation}>{message}</span>}
      </div>
      <R.Button
        id="toast-trigger"
        data-sdr-toast-show
        onClick={() => {
          setGeneration((value) => value + 1);
          setShow(true);
        }}
      >
        Afișează confirmarea
      </R.Button>
      <div
        hidden={!show}
        style={{ display: show ? 'contents' : undefined }}
        data-sdr-toast-example
        onClick={(event) => {
          if (
            event.target instanceof Element &&
            event.target.closest('[data-sdr-dismiss]')
          )
            setShow(false);
        }}
      >
        <R.Toast
          key={generation}
          announce={false}
          returnFocusId="toast-trigger"
          closeLabel="Închide"
        >
          <span data-sdr-toast-message>{message}</span>
        </R.Toast>
      </div>
    </R.Stack>
  );
}
~~~

## Utilizare

Toast este afișat în fluxul normal al paginii, de aceea apare în interiorul exemplului. Componenta nu creează un portal sau o zonă fixă în fereastră; poziționarea aparține aplicației. Mesajul se închide manual, iar returnFocusId indică un element existent la care revine focusul. Dacă aplicația are o regiune de stare permanentă care anunță mesajul, `announce={false}` lasă acea regiune să îl anunțe. Erorile care necesită rezolvare rămân vizibile în pagină.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `children` | `ReactNode` | Da |
| `returnFocusId` | `string` | Da |
| `closeLabel` | `string` | Da |
| `announce` | `boolean \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.



## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
