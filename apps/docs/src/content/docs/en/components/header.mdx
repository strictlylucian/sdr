## Usage

No emblem is shown by default. Supply an institution emblem through the optional emblem prop; use an empty alt when the adjacent service name already identifies it.

The emblem is optional. Omitting it leaves no empty logo space. The example path represents an institution-provided asset; the library does not bundle official insignia.

~~~tsx
<R.Header
  serviceName="Servicii pentru comunitate"
  emblem={
    <img
      src="/institution-emblem.svg"
      alt=""
      width={48}
      height={48}
    />
  }
/>;
~~~


## API

| Property | Type | Required |
|---|---|---|
| `serviceName` | `string` | Yes |
| `href` | `string \| undefined` | No |
| `emblem` | `ReactNode` | No |
| `children` | `ReactNode` | No |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.
