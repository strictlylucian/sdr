~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function ToastExample() {
  const [show, setShow] = useState(false);
  const [generation, setGeneration] = useState(0);
  return (
    <R.Stack>
      <R.Button
        id="toast-trigger"
        data-sdr-toast-show
        onClick={() => {
          setGeneration((value) => value + 1);
          setShow(true);
        }}
      >
        Afișează confirmarea
      </R.Button>
      <div
        hidden={!show}
        style={{ display: show ? 'contents' : undefined }}
        data-sdr-toast-example
      >
        <R.Toast
          key={generation}
          returnFocusId="toast-trigger"
          closeLabel="Închide"
        >
          Modificările au fost salvate.
        </R.Toast>
      </div>
    </R.Stack>
  );
}
~~~

## Utilizare

Mesajul se închide manual. returnFocusId indică un element existent la care revine focusul. Erorile care necesită rezolvare rămân vizibile în pagină.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `children` | `ReactNode` | Da |
| `returnFocusId` | `string` | Da |
| `closeLabel` | `string` | Da |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.



## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
