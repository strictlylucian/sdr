~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function CookieBannerExample() {
  const [choice, setChoice] = useState('');
  return (
    <R.Stack>
      {!choice && (
        <R.CookieBanner
          title="Preferințe pentru cookie-uri"
          acceptLabel="Acceptă cookie-urile opționale"
          rejectLabel="Refuză cookie-urile opționale"
          onAccept={() =>
            setChoice('Ai acceptat cookie-urile opționale în acest exemplu.')
          }
          onReject={() =>
            setChoice('Ai refuzat cookie-urile opționale în acest exemplu.')
          }
        >
          Folosim cookie-uri opționale doar dacă le accepți.
        </R.CookieBanner>
      )}
      <p
        role="status"
        hidden={!choice}
      >
        {choice}
      </p>
    </R.Stack>
  );
}
~~~

## Utilizare

Aplicația pornește scripturile opționale în funcție de alegere și salvează preferința. Componenta nu setează cookie-uri.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `title` | `string` | Da |
| `children` | `ReactNode` | Da |
| `acceptLabel` | `string` | Da |
| `rejectLabel` | `string` | Da |
| `onAccept` | `() => void` | Da |
| `onReject` | `() => void` | Da |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.



## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
