## Exemplu

La trimiterea formularului, răspunsurile se păstrează, iar rezumatul erorilor oferă linkuri către câmpurile de corectat. Mesajele explică ce trebuie schimbat. Datele se validează din nou pe server.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function ValidationRecoveryExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="validation"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <R.InsetText>
        Exemplul pornește de la o cerere cu o eroare. Completează numele pentru
        a continua.
      </R.InsetText>
      <div
        data-sdr-pattern-summary
        hidden={done}
      >
        <R.ErrorSummary
          errors={[
            { href: '#pattern-full-name', message: 'Introdu numele complet.' },
          ]}
          title="A apărut o problemă"
        />
      </div>
      <R.TextInput
        id="pattern-full-name"
        name="full-name"
        label="Nume complet"
        autoComplete="name"
        required
        error={done ? undefined : 'Introdu numele complet.'}
        hint="Folosește un nume fictiv în exemplu."
      />
      <div>
        <R.Button type="submit">Continuă</R.Button>
      </div>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Eroarea a fost corectată în exemplu. Nu s-a trimis o cerere reală.
      </p>
    </form>
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
