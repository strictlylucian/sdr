Lista arată starea fiecărei activități și ce trebuie completat înainte de a o începe. Progresul se salvează pe server, cu posibilitatea de a continua de pe alt dispozitiv dacă serviciul o cere.

## Salvarea și continuarea mai târziu

Textul precizează când se salvează progresul, cât timp este păstrat și cum poate fi reluată cererea în siguranță. Datele personale nu apar în URL-uri. Termenul de expirare este anunțat din timp.

<Preview name="SaveReturn" locale="ro" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function SaveReturnExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="resume"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <h3>Continuă mai târziu</h3>
      <R.TextInput
        id="saved-example-name"
        name="saved-name"
        label="Nume de test"
        defaultValue="Ana Șerban"
        autoComplete="off"
      />
      <div>
        <R.Button type="submit">Salvează pentru mai târziu</R.Button>
      </div>
      <div
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        <R.Alert
          tone="success"
          title="Poți continua cererea"
        >
          <R.Stack gap={3}>
            <p>
              Datele rămân doar în această pagină. Nu sunt păstrate după
              închidere sau reîncărcare.
            </p>
            <R.Link href="#saved-example-name">Continuă completarea</R.Link>
          </R.Stack>
        </R.Alert>
      </div>
    </form>
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
