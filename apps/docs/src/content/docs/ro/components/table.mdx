## Utilizare

Antetele descriu coloanele. Dacă tabelul nu încape, se derulează în propriul container, care poate primi focus.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `caption` | `string` | Da |
| `columns` | `TableColumn[]` | Da |
| `rows` | `TableRow[]` | Da |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Cu sortare

Butoanele din antetele coloanelor sortează datele în browser. Pentru numere formatate, sortValues poate furniza valorile numerice folosite la sortare. Paginarea de pe server se implementează în aplicație.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function DataTableExample() {
  return (
    <R.DataTable
      caption="Cereri pe localități"
      columns={[
        { key: 'city', label: 'Localitate', sortable: true },
        { key: 'count', label: 'Cereri', sortable: true, type: 'number' },
      ]}
      rows={[
        { id: 'brasov', cells: { city: 'Brașov', count: 42 } },
        { id: 'iasi', cells: { city: 'Iași', count: 108 } },
        { id: 'cluj', cells: { city: 'Cluj-Napoca', count: 7 } },
      ]}
      compareText={
        new Intl.Collator(locale, { numeric: true, sensitivity: 'base' })
          .compare
      }
    />
  );
}
~~~
