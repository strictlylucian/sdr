## Confirmarea numărului de telefon

Câmpul pentru cod permite lipirea și folosește autocomplete=one-time-code. Sunt explicate valabilitatea codului și retrimiterea lui. Pentru cei care nu pot primi SMS-uri este necesară o alternativă, precum un apel sau ajutor din partea echipei. Numărul de încercări se limitează pe server.

<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function PhoneConfirmationExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="phone-code"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <h3>Introdu codul din SMS</h3>
      <R.InsetText>
        Exemplu fără trimitere de SMS. Codul de test este 123456.
      </R.InsetText>
      <R.TextInput
        label="Cod de verificare"
        name="security-code"
        type="text"
        inputMode="numeric"
        autoComplete="one-time-code"
        pattern="123456"
        title="Codul de test este 123456."
        required
      />
      <div>
        <R.Button type="submit">Verifică numărul</R.Button>
      </div>
      <R.Details summary="Nu ai primit codul?">
        În acest exemplu nu se trimite un SMS. Folosește codul 123456. Într-un
        serviciu real, aici apar opțiunile de retrimitere sau ajutor.
      </R.Details>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Codul de test este corect. Nu s-a verificat un număr real.
      </p>
    </form>
  );
}
~~~

## Confirmarea adresei de email

Pagina arată adresa folosită și permite corectarea ei. Textul explică valabilitatea linkului și cum se poate retrimite mesajul. După confirmare, utilizatorul vede rezultatul și poate continua de unde a rămas.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function EmailConfirmationExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="email-confirm"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!

        );
      }}
    >
      <h3>Verifică adresa de email</h3>
      <p>
        Într-un serviciu real, linkul de confirmare este trimis la{' '}
        <strong>ana@example.invalid</strong>.
      </p>
      <R.InsetText>
        Acesta este un exemplu. Butonul simulează deschiderea linkului din
        email; nu trimite mesaje.
      </R.InsetText>
      <div>
        <R.Button type="submit">Simulează confirmarea</R.Button>
      </div>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Confirmarea de test a reușit. Poți continua cererea.
      </p>
    </form>
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
