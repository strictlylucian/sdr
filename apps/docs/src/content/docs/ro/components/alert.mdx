## Utilizare

Mesajele statice nu sunt anunțate automat. role=status sau role=alert sunt potrivite doar când contextul unei actualizări dinamice le justifică.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `title` | `ReactNode` | Da |
| `tone` | `Tone \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Banner de notificare

NotificationBanner este un alias pentru Alert, destinat mesajelor despre întregul serviciu. Folosește același API.
