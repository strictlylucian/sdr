## Crearea unui cont

Crearea unui cont se justifică prin nevoile serviciului, mai ales când este vorba de o singură solicitare. Textul explică recuperarea accesului, folosirea datelor personale și alternativele pentru cei care nu pot folosi metoda principală de autentificare.

<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function AccountCreationExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="account"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <h3>Creează un cont pentru cererile tale</h3>
      <R.InsetText>
        Cont demonstrativ. Folosește date fictive; nu se creează un cont real.
      </R.InsetText>
      <R.TextInput
        label="Email"
        type="email"
        autoComplete="username"
        name="account-email"
        required
      />
      <R.PasswordCreationFields
        required
        showLabel="Afișează parola"
        hideLabel="Ascunde parola"
        label="Alege o parolă"
        hint="Folosește o parolă unică. Un manager de parole te poate ajuta."
      />
      <div>
        <R.Button type="submit">Simulează crearea contului</R.Button>
      </div>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Exemplul a fost finalizat. Nu s-au creat conturi și nu s-au salvat
        parole.
      </p>
    </form>
  );
}
~~~

## Alegerea unui nume de utilizator

Un identificator deja folosit poate evita crearea unui nume de utilizator separat, dacă se potrivește serviciului. Formularul explică dinainte caracterele permise și faptul că numele trebuie să fie disponibil. Erorile arată cum poate fi corectat.

  const [done, setDone] = useState(false);
  return (

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
