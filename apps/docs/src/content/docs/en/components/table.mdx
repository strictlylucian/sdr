## Usage

Use a descriptive caption. Horizontal scrolling is limited to the labelled table region.



## API

| Property | Type | Required |
|---|---|---|
| `caption` | `string` | Yes |
| `columns` | `TableColumn[]` | Yes |
| `rows` | `TableRow[]` | Yes |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.

## Sortable table

DataTable adds local sorting through header buttons. Formatted numeric cells can supply sortValues; remote pagination remains an application concern.

<Preview name="DataTable" locale="en" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'en';

export function DataTableExample() {
  return (
    <R.DataTable
      caption="Applications by city"
      columns={[
        { key: 'city', label: 'City', sortable: true },
        { key: 'count', label: 'Applications', sortable: true, type: 'number' },
      ]}
      rows={[
        { id: 'brasov', cells: { city: 'Brașov', count: 42 } },
        { id: 'iasi', cells: { city: 'Iași', count: 108 } },
        { id: 'cluj', cells: { city: 'Cluj-Napoca', count: 7 } },
      ]}
      compareText={
        new Intl.Collator(locale, { numeric: true, sensitivity: 'base' })
          .compare
      }
    />
  );
}
~~~
