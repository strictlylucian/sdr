## Contact și ajutor

Datele de contact includ programul, timpul estimat de răspuns și opțiunile accesibile de comunicare. Textul precizează ce informații sunt necesare pentru rezolvarea solicitării.

## Ajutor pentru folosirea serviciului

Serviciul oferă și ajutor prin telefon, la ghișeu sau prin alte canale accesibile, cu program, costuri și termene de răspuns clare. Testarea include și persoane care folosesc rar internetul sau au nevoie de ajutor la completare.

<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function AssistedSupportExample() {
  return (
    <R.Stack>
      <h3>Ajutor pentru completarea online</h3>
      <p>
        Poți primi ajutor la ghișeu dacă nu poți folosi formularul online. Nu
        este nevoie să ai un dispozitiv propriu.
      </p>
      <R.SummaryList
        items={[
          {
            key: 'Locație de exemplu',
            value: 'Centrul de servicii, Strada Exemplului nr. 1',
          },
          { key: 'Program', value: 'Luni–vineri, 09:00–17:00' },
          { key: 'Cost', value: 'Asistență gratuită' },
        ]}
      />
      <R.InsetText>
        Adresa și programul sunt fictive. Într-un serviciu real, opțiunile de
        sprijin sunt verificate cu instituția.
      </R.InsetText>
    </R.Stack>
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
