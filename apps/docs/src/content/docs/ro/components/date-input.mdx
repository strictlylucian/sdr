## Read-only

Atributul readOnly (readonly în HTML) păstrează valoarea vizibilă și inclusă în datele formularului. Câmpurile de text pot primi focus, iar conținutul poate fi selectat și copiat, fără a putea fi modificat. Navigarea câmpurilor native de dată și oră urmează comportamentul browserului. La grupul de dată și la Fieldset, starea se aplică fiecărui câmp de text.

## Utilizare

Validarea pe server verifică dacă data există și indică ce trebuie corectat: ziua, luna sau anul.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `legend` | `ReactNode` | Da |
| `name` | `string` | Da |
| `hint` | `ReactNode` | Nu |
| `error` | `ReactNode` | Nu |
| `id` | `string \| undefined` | Nu |
| `labels` | `{ day: string; month: string; year: string; }` | Da |
| `disabled` | `boolean \| undefined` | Nu |
| `readOnly` | `boolean \| undefined` | Nu |
| `defaultValue` | `{ day: string; month: string; year: string; } \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.
