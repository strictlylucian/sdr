## Example

Keep equivalent routes and preserve location. Use lang on the document and mark passages in other languages. Do not use national flags as language labels.

<Preview name="LanguageNavigation" locale="en" />

<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'en';

export function LanguageNavigationExample() {
  return (
    <R.LanguageNavigation
      label="Language"
      items={[
        {
          lang: 'ro',
          label: 'Română',
          href: '/ro/components/language-navigation/',
          current: locale === 'ro',
        },
        {
          lang: 'en',
          label: 'English',
          href: '/en/components/language-navigation/',
          current: locale === 'en',
        },
      ]}
    />
  );
}
~~~

</TabItem>

## Service integration

Examples use library components. Server validation, messaging, payment processing and persistence are implemented by the application. Demonstration interactions stay local and do not persist after reload. JavaScript setup is documented once in [Get started](/en/getting-started/). Accessibility details are in [the accessibility guide](/en/accessibility/).
