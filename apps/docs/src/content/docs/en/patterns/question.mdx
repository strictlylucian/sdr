## Example

Ask one coherent question or related group. Use a visible heading, explain why sensitive information is needed and keep the primary action in the reading flow.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'en';

export function QuestionPageExample() {
  const [done, setDone] = useState(false);
  return (
    <R.Stack data-sdr-pattern-demo="question">
      <R.QuestionPage
        title="What is your name?"
        submitLabel="Continue"
        onSubmit={(event) => {
          event.preventDefault();
          const form = event.currentTarget;
          setDone(true);
          requestAnimationFrame(() =>
            form
              .closest('[data-sdr-pattern-demo]')!
              .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
              .focus(),
          );
        }}
      >
        <R.NameFields
          required
          label="Full name"
          hint="Include all given and family names."
        />
      </R.QuestionPage>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Answer accepted in this demonstration. Nothing was submitted.
      </p>
    </R.Stack>
  );
}
~~~

## Service integration

Examples use library components. Server validation, messaging, payment processing and persistence are implemented by the application. Demonstration interactions stay local and do not persist after reload. JavaScript setup is documented once in [Get started](/en/getting-started/). Accessibility details are in [the accessibility guide](/en/accessibility/).
