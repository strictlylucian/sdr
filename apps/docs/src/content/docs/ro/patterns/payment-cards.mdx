## Exemplu

Plata poate folosi pagina sau câmpurile securizate ale unui procesator de plăți specializat. SDR nu procesează plăți cu cardul, iar exemplele din documentație nu colectează date reale de card.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function PaymentCardExample() {
  const [done, setDone] = useState(false);
  const amount = new Intl.NumberFormat('ro-RO', {
    style: 'currency',
    currency: 'RON',
  }).format(25);
  return (
    <form
      data-sdr-pattern-demo="payment"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <h3>Plata taxei pentru document</h3>
      <R.SummaryList items={[{ key: 'Total de plată', value: amount }]} />
      <R.InsetText>
        Plată demonstrativă, fără procesarea banilor. Folosește doar cardul de
        test 4242 4242 4242 4242 și date fictive.
      </R.InsetText>
      <R.TextInput
        label="Numărul cardului"
        name="card-number"
        inputMode="numeric"
        autoComplete="cc-number"
        defaultValue="4242 4242 4242 4242"
        pattern="4242(?:\s|\x2D)*4242(?:\s|\x2D)*4242(?:\s|\x2D)*4242"
        title="Folosește cardul de test 4242 4242 4242 4242."
        required
      />
      <R.Fieldset
        legend="Data expirării"
        hint="De exemplu, 12 2030"
      >
        <div className="sdr-date">
          <R.TextInput
            label="Lună"
            name="card-exp-month"
            inputMode="numeric"
            autoComplete="cc-exp-month"
            defaultValue="12"
            pattern="0[1-9]|1[0-2]"
            maxLength={2}
            required
          />
          <R.TextInput
            label="An"
            name="card-exp-year"
            inputMode="numeric"
            autoComplete="cc-exp-year"
            defaultValue="2030"
            pattern="20[0-9]{2}"
            maxLength={4}
            required
          />
        </div>
      </R.Fieldset>
      <R.TextInput
        label="Numele de pe card"
        name="card-name"
        autoComplete="cc-name"
        defaultValue="ANA ȘERBAN"
        required
      />
      <R.TextInput
        label="Codul de securitate"
        name="card-security"
        inputMode="numeric"
        autoComplete="cc-csc"
        defaultValue="123"
        pattern="[0-9]{3,4}"
        maxLength={4}
        hint="Cele 3 cifre de pe spatele cardului sau cele 4 cifre de pe față, în funcție de card."
        required
      />
      <div>
        <R.Button type="submit">Simulează plata de 25,00 lei</R.Button>
      </div>
      <p
        role="status"
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        Plata de test a fost confirmată. Nu s-au retras bani.
      </p>
    </form>
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
