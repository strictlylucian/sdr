## Save and return

State when progress is saved and how long it is kept. Provide secure resumption without placing personal data in URLs. Explain expiry before it happens.

<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'en';

export function SaveReturnExample() {
  const [done, setDone] = useState(false);
  return (
    <form
      data-sdr-pattern-demo="resume"
      className="sdr-stack"
      onSubmit={(event) => {
        event.preventDefault();
        const form = event.currentTarget;
        setDone(true);
        requestAnimationFrame(() =>
          form
            .closest('[data-sdr-pattern-demo]')!
            .querySelector<HTMLElement>('[data-sdr-pattern-result]')!
            .focus(),
        );
      }}
    >
      <h3>Continue later</h3>
      <R.TextInput
        id="saved-example-name"
        name="saved-name"
        label="Test name"
        defaultValue="Ana Șerban"
        autoComplete="off"
      />
      <div>
        <R.Button type="submit">Save for later</R.Button>
      </div>
      <div
        data-sdr-pattern-result
        tabIndex={-1}
        hidden={!done}
      >
        <R.Alert
          tone="success"
          title="Your application is ready to resume"
        >
          <R.Stack gap={3}>
            <p>
              Details remain only on this page. They are not kept after closing
              or reloading it.
            </p>
            <R.Link href="#saved-example-name">Continue editing</R.Link>
          </R.Stack>
        </R.Alert>
      </div>
    </form>
  );
}
~~~

## Service integration

Examples use library components. Server validation, messaging, payment processing and persistence are implemented by the application. Demonstration interactions stay local and do not persist after reload. JavaScript setup is documented once in [Get started](/en/getting-started/). Accessibility details are in [the accessibility guide](/en/accessibility/).
