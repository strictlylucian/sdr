## Stare de eroare

Mesajul de eroare este asociat controlului prin aria-describedby, iar aria-invalid indică starea. În React, proprietatea error activează prezentarea; aplicația stabilește regulile de validare și momentul afișării mesajului. Ediția HTML folosește aceeași structură și aceleași clase CSS.

## Read-only

Atributul readOnly (readonly în HTML) păstrează valoarea vizibilă și inclusă în datele formularului. Câmpurile de text pot primi focus, iar conținutul poate fi selectat și copiat, fără a putea fi modificat. Navigarea câmpurilor native de dată și oră urmează comportamentul browserului. La grupul de dată și la Fieldset, starea se aplică fiecărui câmp de text.

## Utilizare

Câmpul acceptă diacritice și text copiat. autocomplete și inputMode se aleg în funcție de informația cerută.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `label` | `ReactNode` | Da |
| `hint` | `ReactNode` | Nu |
| `error` | `ReactNode` | Nu |
| `id` | `string \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.

## Parolă

Câmpul permite afișarea și ascunderea parolei. autocomplete indică dacă este o parolă existentă sau una nouă. Lipirea textului și managerii de parole rămân disponibili.

<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx

import * as R from '@sdr/react';

const locale = 'ro';

export function PasswordInputExample() {
  return (
    <R.PasswordInput
      label="Parolă"
      name="password"
      autoComplete="new-password"
      hint="Poți folosi un manager de parole."
      showLabel="Afișează parola"
      hideLabel="Ascunde parola"
    />
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html

      <label
        class="sdr-label"
~~~

## Cu mesaj de eroare

Proprietatea error leagă mesajul de câmp și îl marchează ca invalid. ErrorMessage poate fi folosit și separat în formulare personalizate.

~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function ErrorMessageExample() {
  return (
    <R.TextInput
      label="Email"
      type="email"
      name="invalid-email"
      defaultValue="alex@"
      error="Scrie o adresă de email completă, de exemplu nume@exemplu.ro."
    />
  );
}
~~~
