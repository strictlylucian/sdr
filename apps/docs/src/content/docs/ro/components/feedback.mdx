~~~tsx
import { useState } from 'react';
import * as R from '@sdr/react';

const locale = 'ro';

export function FeedbackExample() {
  const [answered, setAnswered] = useState(false);
  return (
    <R.Stack>
      <R.Feedback
        question="Ți-a fost utilă această pagină?"
        yesLabel="Da"
        noLabel="Nu"
        onAnswer={() => setAnswered(true)}
      />
      <p role="status">{answered && 'Mulțumim pentru răspuns.'}</p>
    </R.Stack>
  );
}
~~~

## Utilizare

Aplicația colectează răspunsurile și gestionează protecția datelor. Această întrebare nu este destinată colectării datelor personale.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `question` | `string` | Da |
| `yesLabel` | `string` | Da |
| `noLabel` | `string` | Da |
| `onAnswer` | `(helpful: boolean) => void` | Da |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.



## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
