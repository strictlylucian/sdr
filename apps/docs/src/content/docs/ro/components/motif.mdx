## Utilizare

Patru dimensiuni: sm (24px), md (48px, implicit), lg (64px) și xl (96px). Desenul se scalează proporțional. Decorul rămâne separat de text și controale.



## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| undefined` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.



## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
