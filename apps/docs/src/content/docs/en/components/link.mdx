## Usage

Write destination-specific text and preserve browser link behaviour.



## API

Accepts HTML attributes for its native element. See the typed source.

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.

## Back link

The back-arrow variant receives an explicit destination. Navigation does not depend on browser history.

<Preview name="BackLink" locale="en" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'en';

export function BackLinkExample() {
  return (
    <R.BackLink
      href={`/${locale}/components/`}
      children="Back"
    />
  );
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div
  lang="en"
  data-sdr-theme="light"
  data-sdr-density="comfortable"
  class="sdr"
>
  <a
    href="/en/components/"
    class="sdr-back"
    ><span aria-hidden="true">←</span>Back</a
  >
</div>
~~~

[Initial setup](/en/getting-started/)

</TabItem>
</Tabs>
</div>


[Open the portable variant](/examples/en/back-link.html)

## Back to top

The upward-arrow variant navigates to the document start anchor.

<Preview name="BackToTop" locale="en" />


<div className="sdr-example-code">
<Tabs>
<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'en';

export function BackToTopExample() {
  return <R.BackToTop href="#_top">Back to top</R.BackToTop>;
}
~~~

</TabItem>
<TabItem label="HTML">


~~~html
<div

  data-sdr-density="comfortable"
  class="sdr"

  <a
    href="#_top"
    class="sdr-back"

~~~

## Accessibility

Composition accessibility depends on labels, element semantics, focus order and application context. Library themes and behaviours are checked against the documented examples; those results do not assess the consuming service. The matrix and limitations are described in [the accessibility guide](/en/accessibility/).
