## Utilizare

Emblema este opțională și se transmite prin emblem. Dacă numele alăturat identifică deja instituția, imaginea poate avea alt gol, pentru a evita repetarea.

Emblema este opțională; în lipsa ei, nu rămâne spațiu gol pentru logo. Calea din exemplu indică o imagine furnizată de instituție. Biblioteca nu include însemne oficiale.

~~~tsx
<R.Header
  serviceName="Servicii pentru comunitate"
  emblem={
    <img
      src="/institution-emblem.svg"
      alt=""
      width={48}
      height={48}
    />
  }
/>;
~~~


## API

| Proprietate | Tip | Obligatorie |
|---|---|---|
| `serviceName` | `string` | Da |
| `href` | `string \| undefined` | Nu |
| `emblem` | `ReactNode` | Nu |
| `children` | `ReactNode` | Nu |

Componentele acceptă atribute HTML native, aria-* și data-* în limita tipurilor declarate. Tabelul proprietăților este generat din sursele TypeScript.



## Accesibilitate

Accesibilitatea unei pagini depinde și de etichete, structura HTML, ordinea de navigare cu tastatura și modul în care sunt combinate componentele. Verificările bibliotecii acoperă exemplele documentate, nu întregul serviciu. Rezultatele și limitele sunt prezentate în [ghidul de accesibilitate](/ro/accessibility/).
