## Exemplu

Numele serviciului și denumirile zonelor de navigare rămân consecvente. Când navigarea se face fără reîncărcarea paginii, aplicația actualizează și titlul, istoricul, focusul și mesajele pentru cititoarele de ecran.

<TabItem label="React">


~~~tsx
import { useState } from 'react';
import * as R from '@strictlylucian/sdr-react';

const locale = 'ro';

export function ServiceNavigationExample() {
  return (
    <R.ServiceNavigation
      label="Serviciu"
      items={[
        { label: 'Prezentare', href: `/${locale}/`, current: true },
        { label: 'Componente', href: `/${locale}/components/` },
      ]}
      menuLabel="Meniu"
    />
  );
}
~~~

## Integrarea într-un serviciu

Exemplele folosesc componentele bibliotecii. Validarea pe server, trimiterea mesajelor, procesarea plăților și salvarea datelor sunt implementate de aplicație. Interacțiunile demonstrative sunt locale și nu salvează date după reîncărcare. Încărcarea JavaScript-ului este descrisă o singură dată în [Instalare și integrare](/ro/getting-started/). Detaliile despre accesibilitate se găsesc în [ghidul de accesibilitate](/ro/accessibility/).
