## Usage

Preserve filters in generated URLs and announce result changes in client-routed applications.



## API

| Property | Type | Required |
|---|---|---|
| `page` | `number` | Yes |
| `pages` | `number` | Yes |
| `href` | `(page: number) => string` | Yes |
| `label` | `string` | Yes |
| `previousLabel` | `string` | Yes |
| `nextLabel` | `string` | Yes |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.



## Accessibility

Composition accessibility depends on labels, element semantics, focus order and application context. Library themes and behaviours are checked against the documented examples; those results do not assess the consuming service.
