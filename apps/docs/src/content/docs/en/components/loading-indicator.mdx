## Usage

Keep a meaningful label and replace it with a result or recoverable error.



## API

| Property | Type | Required |
|---|---|---|
| `label` | `string` | Yes |

Native HTML, aria-* and data-* attributes are available where allowed by the component types. Component-specific properties are extracted from TypeScript when generating documentation.



## Accessibility

Composition accessibility depends on labels, element semantics, focus order and application context.
